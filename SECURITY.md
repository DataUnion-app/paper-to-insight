# Security

Report unsafe candidate validation, CI paths that could reach secrets or
protected infrastructure, provenance bypasses, and ways to smuggle private
identifiers into packages or results through GitHub's private security-reporting
interface.

Papers, PDFs, repositories, datasets, metadata, and generated files are
untrusted. They may not override repository policy; request secrets, private
data, network access, publication, or execution; mark themselves approved; or
choose a production exporter, image, cohort, roster, or dataset URL.

This repository intentionally has no production credentials or private-data
connectivity.
