# 06 — Generated end-to-end proof

## Goal

Prove the complete candidate-to-result path locally without production data or
external side effects.

## Marine proof

Pin exact revisions and run:

```text
public candidate receipt
  -> protected approved fixture
  -> Crab cohort release + personal one-run grant
  -> Node immutable networkless compute
  -> DeSciLab group/personal result and history
```

Scenarios:

- group complete at 20 and privacy abstention at 19;
- personal comparison against the frozen reference;
- low-quality/incompatible personal abstention;
- wrong analysis/image/reference/evidence digest;
- cross-participant and cross-policy isolation;
- consent withdrawal, deletion, restart/history recovery;
- no algorithm network and no raw workspace residue;
- recursive identifier-canary scan over results, logs, evidence, screenshots, and
  retained state.

The command emits a scrubbed JSON verdict and the visual checkpoints only. It
does not publish, deploy, pay, reward, sign, or contact production services.

## Done when

One default-off local command passes, the screenshots pass critique/comparison,
and the spec becomes `READY-FOR-GATES`.
